# CSI 选课规划（简单版）

纽约市立大学史坦顿岛学院（CUNY CSI）— 心理学、信息系统与信息学（ISI）、经济学。

用法：选专业方向，勾选已修过的课，页面会算还剩几个组、多少学分。勾选只存在你自己的浏览器里。

数据来源：CSI 各系目录 PDF（2025-09-16 版），地图标注为“2024-PRESENT”。
源数据见 `data/catalog-v2.json`。

重要边界（不是小字）：
- 不直连 DegreeWorks，不是官方建议，正式决定前请拿 DegreeWorks 和导师再对一遍。
- PDF 里没有印一个确定的目录年份，也没有写专业总学分；学期只是地图里放这门课的位置，不代表那学期一定开课。
- 只有心理学 BS 交叉核对过（列出的组加起来 45 学分，和 DegreeWorks What-If 排名对得上）。其他专业在页面里都标了各自的缺口。
- 通识课（Pathways，共 42 学分）不算在专业组里。
